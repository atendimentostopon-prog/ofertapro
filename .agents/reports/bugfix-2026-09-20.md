# Bugfix — rollout de `api-key-reveal`

Data: 20/09/2026

## Bug 1 — rollout incompleto das funções de API key

### Descrição

O frontend invoca `api-key-reveal`, mas o procedimento versionado de deploy
listava somente `api-key-generate`, `api-key-revoke` e `public-api`. O guia
também não tornava explícita a dependência e a ordem da migration do Vault.

### Causa raiz

- `API_E_INTEGRACOES_LINK_OFERTA.md:149-154` (antes da correção): checklist de
  deploy incompleto, sem `api-key-reveal` e sem a migration do Vault.
- `supabase/migrations/20260831010200_bot_configs_api_key_vault.sql:24`: havia
  somente a referência genérica a `api-key-*`, insuficiente para impedir a
  omissão de uma função no rollout.

### Correção aplicada

- O guia agora documenta `api-key-reveal` e exige a ordem coordenada: atualizar
  o consumidor externo, aplicar a migration, implantar `api-key-generate`,
  `api-key-reveal` e `api-key-revoke`, e então executar smoke tests seguros.
- O comentário operacional da migration nomeia explicitamente as três funções.
- Foi conferido que migration e funções usam os mesmos RPCs e parâmetros:
  `get_bot_config_api_key(p_user_id)` e
  `set_bot_config_api_key(p_user_id, p_key)`, restritos a `service_role`.
- Nenhum segredo foi lido e nenhuma operação remota foi executada.

### Teste que cobre

`scripts/check-api-key-rollout.mjs`, executado por
`npm run check:api-key-rollout`, valida:

- presença e permissões dos dois RPCs na migration;
- uso coerente dos RPCs por generate, reveal e revoke;
- presença das três funções no guia;
- migration posicionada antes dos comandos de deploy.

### Resultado antes/depois

- Antes: falhou com `guia nao menciona a migration do Vault`.
- Depois: passou com `API key rollout checks passed`.
- `npm run lint`: passou com 0 erros e 26 warnings preexistentes, inclusive em
  worktree alheia; nenhum warning pertence aos arquivos alterados.
- `npm run build`: passou (TypeScript + Vite, 2525 módulos).
- `npm run check:plan-limits`: passou.
- `npm run check:billing`: passou.
- `git diff --check`: passou.
- `deno` e Supabase CLI não estão instalados; não foi possível executar check
  nativo das Edge Functions nem teste local do banco.

### Commit

`fix: inclui api-key-reveal no rollout (causa: checklist de deploy incompleto)`

### Risco residual

Médio até o rollout coordenado ser executado pelo dono. Migration, bot externo e
as três Edge Functions precisam ser implantados na mesma janela. A validação
remota de existência/versão das funções e o smoke test autenticado continuam
pendentes porque deploy e acesso a produção não foram autorizados.

## Bugs não corrigidos

Nenhum dentro do escopo da Opção 1. Não foram incluídas as melhorias de
observabilidade da Opção 2, pois seriam uma mudança adicional ao rollout pedido.

## Padrões parecidos encontrados

Não há outro checklist versionado que implante o conjunto de funções de API key.
Referências antigas a `public-api` em relatórios históricos não são procedimentos
ativos e foram preservadas.
