## Divergências encontradas

- O papel inicial descrevia Next.js App Router; o código real é React 19 + Vite + React Router.
- Não existem middleware, Server Components, Server Actions ou Route Handlers. O backend são Edge Functions Supabase, PostgREST, RPCs e triggers.
- O PSP ativo é Cakto; Stripe aparece apenas em rastros/nomenclatura histórica de provider.
- O README anterior era o texto padrão do template React/Vite e não descrevia o produto.
- Scripts SQL soltos na raiz contêm versões antigas de tabelas/policies; migrations posteriores restringem acesso público por views.
- Migrations antigas criaram expiração automática de ofertas, mas `20260903180000_disable_offer_ttl.sql` a desativou.
- O produto oferece apenas cobrança mensal, apesar de banco/tipos ainda aceitarem `yearly`.
- A configuração do ambiente documentava apenas variáveis do front, não os secrets das Edge Functions.
