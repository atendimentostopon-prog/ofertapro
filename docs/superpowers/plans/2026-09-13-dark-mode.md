# Dark Mode Completo (Aflyo) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adicionar dark mode completo ao app principal do Aflyo (`app.aflyo.com.br`), com toggle no `TopBar` entre "Nova Oferta" e o sino de notificações, persistindo a escolha do usuário.

**Architecture:** Os tokens de cor do Tailwind (`surface`, `ink`, `line`, `success/warning/danger/info.bg/ink`) passam a apontar para variáveis CSS já existentes em `src/index.css`; um bloco `.dark { ... }` redefine essas variáveis para os valores escuros. `next-themes` aplica/remove a classe `.dark` na tag `<html>` e persiste a escolha no `localStorage`. Um componente `ThemeSwitch` (shadcn) no `TopBar` alterna o tema.

**Tech Stack:** React 19 + Vite + TypeScript, Tailwind CSS, `next-themes`, Radix UI (`react-switch`, `react-label`), `class-variance-authority`, `lucide-react` (já instalado).

## Global Constraints

- Escopo: só o app principal (`src/`). Painel admin (`admin/`) e landing page (repo separado) ficam de fora.
- Tema padrão para todo usuário: **claro**. Sem detecção de tema do SO (`enableSystem={false}`).
- Persistência via `next-themes` com `storageKey="aflyo-theme"`.
- Cores de marca (`mint`, `graphite` em si) não mudam de tom entre os temas — só superfícies, texto, bordas e os pares `bg`/`ink` dos sinais (`success`/`warning`/`danger`/`info`).
- Nenhum teste automatizado de UI existe no projeto hoje (`npm run build` roda `tsc -b && vite build` — é a única verificação automatizada disponível). Verificação de UI é manual, via `run`/navegador, nos dois temas.
- Referência: `docs/superpowers/specs/2026-09-13-dark-mode-design.md`.

### Task 6: Componente `ThemeSwitch`

**Files:**
- Create: `src/components/theme/ThemeSwitch.tsx`

**Interfaces:**
- Consumes: `useTheme()` de `next-themes` (Task 4), `Switch`/`Label` (Task 5), ícones `Sun`/`Moon` de `lucide-react`.
- Produces: `<ThemeSwitch />` — componente sem props, usado pela Task 7 no `TopBar`.

- [ ] **Step 1: Criar `src/components/theme/ThemeSwitch.tsx`**

```tsx
import React from 'react';
import { useTheme } from 'next-themes';
import { Sun, Moon } from 'lucide-react';
import { Switch } from '../ui/switch';
import { Label } from '../ui/label';

const ThemeSwitch: React.FC = () => {
  const { resolvedTheme, setTheme } = useTheme();
  const isDark = resolvedTheme === 'dark';

  return (
    <div className="flex items-center gap-1.5">
      <Label htmlFor="theme-switch" className="sr-only">
        Alternar tema claro/escuro
      </Label>
      <Switch
        id="theme-switch"
        checked={isDark}
        onCheckedChange={(checked) => setTheme(checked ? 'dark' : 'light')}
        aria-label={isDark ? 'Mudar para tema claro' : 'Mudar para tema escuro'}
      />
      {isDark ? (
        <Moon className="w-4 h-4 text-ink-secondary" />
      ) : (
        <Sun className="w-4 h-4 text-ink-secondary" />
      )}
    </div>
  );
};

export default ThemeSwitch;
```

`resolvedTheme` (em vez de `theme`) evita um flash de estado indefinido durante a hidratação inicial do `next-themes`.
